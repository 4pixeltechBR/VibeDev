# VibeDev is not a low-code builder

VibeDev assumes the user wants to **understand the code** they're shipping. It is not a no-code/low-code platform.

## What VibeDev does
- Walks you through phases that involve reading and writing code
- Generates code with your involvement
- Explains trade-offs in technical terms when in `modo_usuario: tecnico`
- Glossário (in `modo_usuario: leigo`) translates jargon but does not hide the code

## What VibeDev does NOT do
- Hide code behind a visual editor
- Generate apps from pure drag-and-drop
- Replace understanding of stack, database, or APIs
- Promise "no programming required"

## If you want low-code
- **Bubble** for web apps
- **Glide** for mobile apps from spreadsheets
- **Retool** for internal tools
- **FlutterFlow** for Flutter apps

These are different products for different audiences. VibeDev is for people who want to ship code and understand it.

## Why this is out of scope

VibeDev's value proposition is **disciplined construction with understanding**. A no-code builder serves a different audience (people who want output, not learning). Trying to serve both dilutes both.
