# Out of Scope — VibeDev

> Documenta coisas que VibeDev **deliberadamente não faz** e por quê.
> Inspirado em [mattpocock/skills/.out-of-scope](https://github.com/mattpocock/skills/tree/main/.out-of-scope) (referência competitiva, ver `CREDITS.md`).

## Como usar este diretório

Antes de abrir issue ou PR pedindo uma feature nova, verifique aqui. Se a feature está listada, a issue provavelmente será fechada com link pra cá.

## Conteúdo

| Arquivo | O que NÃO fazemos |
|---|---|
| `not-a-ci-cd-tool.md` | VibeDev governa projeto, não faz deploy/CD |
| `not-for-monorepos.md` | VibeDev é por projeto, não pra multi-package workspaces |
| `not-an-issue-tracker.md` | Não substitui GitHub Issues, Linear, Jira |
| `not-a-low-code-builder.md` | VibeDev pressupõe que você quer entender o código |
| `not-replacement-for-vibeshield.md` | VibeShield é satélite, não deve ser mergeado em VibeDev |
| `not-providing-stack-recommendations.md` | Não diz "use X framework" — apresenta opções com trade-offs |
| `not-pretending-to-be-vibeshield.md` | VibeDev não faz auditoria de segurança (papel da VibeShield) |
