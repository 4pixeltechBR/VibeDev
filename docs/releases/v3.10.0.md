# Release v3.10.0 — Baixa fricção / Low friction

🌍 **Read in / Leia em:** [English](#-english) | [Português](#-português)

---

## 🇺🇸 English

**Release date:** 2026-10-21
**Type:** Behavior change. The skill that loads every session is now a short protocol.

### What changed

- `vibedev/SKILL.md` dropped from about 33 KB to about 6 KB. References and command files open only when the step needs them.
- A new project asks up to four questions in one message, then builds the smallest visible slice.
- Existing code gets three rescue questions and one fix for this week.
- An approved plan runs through `/vd-build` and stops on a risky decision, a failure, or the end of the plan.
- Cost, Country Mode, scaffold, the premortem, and VibeShield run only when the choice is hard to undo: login, payment, personal data, publish, a database that already has data, or irreversible delete.
- Speaking Portuguese by itself no longer turns Country Mode on.
- New glossary terms go into the project's `PROJECT_STATE.md`. The installed skill is not edited mid-project.

### Install

Copy `vibedev/` into the skills folder of your agent and restart the session. The zip shipped with v3.7.0 is the previous package.

### Check

In a new chat:

```
Do you have VibeDev 3.10.0 loaded?
What do you do with a new idea before writing code?
When do cost, Country Mode, and VibeShield show up?
```

Expected: one message with up to four questions, then a visible slice. Cost, country, and VibeShield show up only on a hard-to-undo choice.

## 🇧🇷 Português

**Data:** 2026-10-21
**Tipo:** Mudança de comportamento. A skill que carrega em toda sessão virou um protocolo curto.

### O que mudou

- `vibedev/SKILL.md` caiu de cerca de 33 KB para cerca de 6 KB. Referências e comandos abrem só quando o passo precisa.
- Projeto novo: até 4 perguntas numa mensagem e a menor coisa visível.
- Código existente: 3 perguntas de resgate e um conserto desta semana.
- O plano aprovado roda no `/vd-build` e para em decisão de risco, falha, ou no fim.
- Custo, Modo País, scaffold, pré-mortem e VibeShield entram só quando a escolha é difícil de desfazer: login, pagamento, dado pessoal, publicar, banco que já tem dados, ou apagar sem volta.
- Falar português sozinho não liga o Modo País.
- Termo novo do glossário vai para o `PROJECT_STATE.md` do projeto. A skill instalada não é editada no meio do projeto.

### Instalação

Copie `vibedev/` para a pasta de skills do agente e reinicie a sessão. O zip da v3.7.0 é o pacote anterior.

### Conferência

Num chat novo:

```
Você tem o VibeDev 3.10.0 carregado?
O que você faz com uma ideia nova antes de escrever código?
Quando aparecem custo, Modo País e VibeShield?
```

Esperado: uma mensagem com até 4 perguntas e depois uma coisa visível. Custo, país e VibeShield só numa escolha difícil de desfazer.
